# 1588BS 8×8 点阵

1.5 吋红色 8×8 LED 点阵（1588BS，共阳），ESP32-C6 + esp-hal/embassy 逐行扫描驱动，
上电后循环播放四帧图案：全亮 → 棋盘 → 心形 → 叉号，每帧 1 秒。

- 栈：`esp-hal 1.2` + `esp-rtos` + `embassy`（`#[esp_rtos::main]`）
- 日志：`defmt` over RTT（不是串口）

## 接线

16 根脚全用上：行（阳极）8 根、列（阴极）8 根。**行串 1kΩ 限流**，列直连 GPIO——
一行点亮时 8 个点共用这一根行线，`(3.3V - 1.9V) / 1kΩ ≈ 1.4mA/点`，8 点约 11mA，
远低于 GPIO 的 40mA 上限。想更亮把行电阻降到 470Ω（约 24mA），不建议再低。

| 矩阵脚 | 功能 | GPIO |  | 矩阵脚 | 功能 | GPIO |
|---|---|---|---|---|---|---|
| 9  | ROW1（阳极） | 0  |  | 13 | COL1（阴极） | 10 |
| 14 | ROW2         | 1  |  | 3  | COL2         | 11 |
| 8  | ROW3         | 2  |  | 4  | COL3         | 18 |
| 12 | ROW4         | 3  |  | 10 | COL4         | 19 |
| 1  | ROW5         | 4  |  | 6  | COL5         | 20 |
| 7  | ROW6         | 5  |  | 11 | COL6         | 21 |
| 2  | ROW7         | 6  |  | 15 | COL7         | 22 |
| 5  | ROW8         | 7  |  | 16 | COL8         | 23 |

引脚编号：正面朝向自己、丝印那侧朝下，**左下角是 1 脚**，逆时针 1–16（即下排左→右 1–8，
上排右→左 9–16）。行列不是「下排一行、上排一列」，必须按上表接。

引脚定义来自 `1588BS.pdf`（芯斯美 XSM-D1588B 规格书）与同系列 ELM-1588BS 规格书的
`Common PIN: 9,14,8,12,1,7,2,5`（共阳端即行）。

GPIO 选择：nanoESP32-C6 排针实际只引出 `0-13, 15, 18-23`，其中 9（BOOT）、12/13（USB-JTAG）、
16/17（串口）、15（JTAG strapping）、8（板载 WS2812）避开后正好剩 16 根。

## 运行

```bash
cargo run --release      # probe-rs 烧写并挂 RTT
```

## 实现要点

- 逐行扫描：一次只拉高一根行线，同时按行内容设 8 根列线（低电平点亮），每行保持 1ms。
  一圈 8ms ≈ 125Hz，看上去整片同亮。
- `FRAMES` 每帧是 `[u8; 8]`，下标 = 行，`bit7` = 最左列，所以字面量写成 8×8 点阵的样子就能直接读。
- 换行时上一行已拉低，改列电平不会点亮任何点，所以不需要额外消隐。
- 棋盘帧用来检查行/列有没有接反：斜向条纹说明行/列对调了。
