# baike 单个数码管（10 引脚，共阴）

10 脚单位数码管：A–G 七段 + 小数点 DP + 两个内部连通的公共端。ESP32-C6 + esp-hal/embassy
静态驱动，上电后 0–9 每秒加一循环；小数点只在轮首的 `0` 上亮 1 秒，其余时间灭。

## 接线

引脚定义是**实测**出来的（下面 pins 一列），不来自手册：

> 正面朝自己，左下角为 1 脚，逆时针数：`e d com c dp b a com f g`，即
> 1=e、2=d、3=com、4=c、5=dp、6=b、7=a、8=com、9=f、10=g；3、8 两脚是同一个公共端。

| 段 | 数码管脚 | GPIO |  | 段 | 数码管脚 | GPIO |
|---|---|---|---|---|---|---|
| A  | 7  | 0 |  | E  | 1  | 4 |
| B  | 6  | 1 |  | F  | 9  | 5 |
| C  | 4  | 2 |  | G  | 10 | 6 |
| D  | 2  | 3 |  | DP | 5  | 7 |
| COM | 3、8 | GND | |  |  |  |

- **共阴**：公共端接 GND，段选拉高点亮（`SEG_ON = Level::High`）。换成共阳管子时把
  `SEG_ON` / `SEG_OFF` 对调、公共端改接 3V3，段码表不用动。
- 每段串一只 220–330Ω 限流电阻。**不要**在公共端串一只总电阻，否则显示不同数字时亮度会跟着变。
- 公共端直接接 GND，不走 GPIO：八段同亮时公共端要过几十 mA，超过 ESP32-C6 单脚灌入能力。
- 3、8 脚内部导通，接任意一根到 GND 即可。

`1digit-7seg-LTS-360.pdf` 只用来查电气参数（Vf ≈ 2.0V、单段 20mA）。**它的引脚表不适用**：
Lite-On 那份是 `1&6=COM` 的排法，跟这只管子实测的 `3&8=COM` 完全不同，照抄会一根都点不亮。

## 运行

```sh
cargo run --release      # probe-rs 烧写并挂 RTT，日志里每位数一行
```

## 实现要点

- `FONT` 的 bit0..7 = A B C D E F G DP，置位表示该段点亮；点亮电平由 `SEG_ON` 决定，段码表与极性解耦。
- 单个数码管是静态显示，不需要扫描消隐，`show()` 直接写 8 个引脚。
- 排查接线时可以只点亮单段：`show_mask(1 << bit)`，bit 0..7 即 A..G、DP，对应 GPIO 0..7。

## 排查记录

- 只显示 `8.` 时只有 E 段亮 → 当时按手册的 `1&6=COM` 接线、且按共阳驱动，等于把 3V3 灌在段线上，
  某一根段被静态点亮。实测确认公共端在 3、8 脚且为共阴后，改这两处即正常。
